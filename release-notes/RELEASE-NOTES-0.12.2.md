PC Tweaker Uninstaller 0.12.2 makes leftover cleanup safer.

- Leftovers are matched to the program's own name, never to its publisher, so settings shared by other products from the same vendor stay where they are.
- An install folder is offered for cleanup only when no other installed program lives in it.
- Registry keys are saved to a .reg file before removal and are no longer selected by default.
- The report says a restore point was requested rather than created, since Windows keeps at most one a day.
- Pro keeps working offline with the licence saved on this PC.
